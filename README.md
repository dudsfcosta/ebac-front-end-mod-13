# 🎓 EBAC — Módulo 13: Estilização com SASS

## 📖 Sobre

Página de demonstração do uso de SASS/SCSS, com os estilos organizados em arquivos parciais:

```
├── index.html
├── css/                  # CSS compilado
└── sass/
    ├── estilos.scss      # arquivo principal
    ├── _variaveis.scss   # variáveis de cor/tipografia
    ├── _mixin.scss       # mixins reutilizáveis
    ├── _cabecalho.scss
    └── _conteudo.scss
```

## 🚀 Como visualizar

Abra o `index.html` no navegador (o CSS já está compilado em `css/`).

## 🛠️ Tecnologias

HTML5 • SASS/SCSS

## 💡 O que aprendi

- Organização de estilos em parciais SASS (`_arquivo.scss`) com `@import`
- Variáveis e mixins para evitar repetição de código
- Fluxo de compilação: `.scss` → `.css`
